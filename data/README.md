# data

Simulated datasets for the demo. No real personal data, ever.

## perfiles-30x.csv

Ejemplos anonimizados de los tipos de perfiles que llegan a 30X (697 filas, sin datos
personales), compartidos por 30X como recurso del Reto JEV del Hackathon 30X
(hoja pública "Ejemplos de los tipos de perfiles que llegan a 30X"). Se usa para la demo
de segmentación de inscritos; la columna "Programa sugerido" sirve como etiqueta para medir
el acierto.
